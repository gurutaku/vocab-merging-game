WORD MERGE QUEST — Drag & Drop Edition

Files:
- index.html: complete standalone game. No build step or external JavaScript libraries required.

How to play:
1. Open index.html or use VS Code Live Server.
2. Drag a word tile and drop it onto a second tile.
3. A correct compound word triggers a colourful confetti burst and a cheerful chime.
4. An incorrect pair plays a soft two-note “boo-boo” sound and highlights the tiles in pink.
5. Score points in 90 seconds; quick successful merges build combo bonuses.

Controls:
- Mouse: click and hold a tile, drag it over another tile, then release.
- Touch: press and drag a tile onto another tile.
- Hint highlights a possible pair; drag the first tile onto the second.
- Shuffle rearranges tiles; Restart starts a fresh round.

Audio is synthesized locally using Web Audio after a user gesture; no audio files or external JavaScript libraries are required. Confetti is drawn locally on a canvas.
